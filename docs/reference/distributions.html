VM.distributions

Closed-form densities and masses, CDFs and quantiles, hypothesis tests, and helpers to plot them

Every *Pdf and *Pmf is a pure (x, …params) => number evaluated straight from the formula – no sampling, no random numbers – so a curve drawn from one is exact and doesn’t jitter when a slider moves. Conventions, so you don’t have to check each one:

  • Out of support or an invalid parameter returns 0, never NaN, null or a throw. A slider dragged to variance = 0 draws a flat line, not a broken chart.
  • Discrete masses return 0 at non-integer k. Sample them with sampleCurve(..., {discrete: true}).
  • Parameterizations are called out where textbooks disagree: normalPdf takes a variance, gammaPdf a rate, weibullPdf a scale, geometricPmf counts trials until the first success.
  • Every factorial and Beta-function normalizing constant goes through logGamma, in log space, so binomialPmf(k, 500, p) is an ordinary number rather than an overflow.
VM = window.VM
vmTheme = Generators.observe(notify => VM.plotting.onThemeChange(notify))
chartColors = VM.plotting.colors(vmTheme)

Helpers

VM.distributions.logGamma(x)

ln |Γ(x)| by Lanczos approximation (g = 7, n = 9; reflection formula below 0.5), accurate to ~15 significant digits for x > 0. The shared building block behind every normalizing constant here. The absolute value matters only for negative x, where Γ changes sign: logGamma(-0.5) is ln(2√π).

Parameter Type Description
x number Any real.

Returns number – Infinity at the poles (0 and the negative integers).

[VM.distributions.logGamma(5), Math.log(24), VM.distributions.logGamma(0.5), Math.log(Math.sqrt(Math.PI))]

VM.distributions.logChoose(n, k)

ln C(n, k) through logGamma, finite where C(n, k) itself overflows (C(2000, 1000) has 600 digits). The binomial, negative binomial and hypergeometric PMFs are built on it.

Parameter Type Description
n number
k number

Returns number – logGamma(n + 1) − logGamma(k + 1) − logGamma(n − k + 1); -Infinity when k < 0 or k > n for integer arguments (C is 0 there). Real arguments are not rejected: they give the gamma-function generalization.

[VM.distributions.logChoose(10, 3), Math.log(120), VM.distributions.logChoose(2000, 1000)]

VM.distributions.sampleCurve(fn, lo, hi, opts?)

Samples a function over [lo, hi] into parallel arrays ready for a Plotly trace or a Plot.line.

Parameter Type Default Description
fn (x) => number Typically a *Pdf/*Pmf with its parameters bound: x => VM.distributions.normalPdf(x, 0, 1).
lo, hi number The range, both ends inclusive.
opts.discrete boolean false Evaluate only at the integers from ceil(lo) to floor(hi) – what a PMF has support on – instead of on a fine grid. opts.n is ignored; the arrays are empty if no integer lies in the range.
opts.n number 400 Number of evenly spaced samples in continuous mode, both endpoints included. n = 1 samples lo alone; n < 1 gives empty arrays.

Returns {xs: number[], ys: number[]}.

VM.distributions.sampleCurve(k => VM.distributions.poissonPmf(k, 2), 0, 5, {discrete: true})

VM.distributions.histogramBins(samples, binCount, range?)

Bins an array of draws into equal-width bins, normalized to densities so the bars’ total area is ~1 and a theoretical curve overlays directly.

Parameter Type Default Description
samples number[] The draws.
binCount number Number of bins (≥ 1).
range {lo, hi} samples’ min/max A fixed bin range. Pass {lo: min − 0.5, hi: max + 0.5} with binCount = max − min + 1 for one bin centered on each integer. Samples outside an explicit range are clamped into the first/last bin, not dropped. A zero-width range is widened to [lo − 0.5, hi + 0.5].

Returns {edges: number[], centers: number[], densities: number[]} – binCount + 1 edges; binCount centers and densities, where densities[i] = count[i] / (finiteCount · width). Non-finite samples (NaN, ±Infinity) are dropped first, so the area stays 1. All three arrays are empty when samples has no finite entry or binCount < 1.

{
  const gaussian = VM.sampling.gaussianRandom(VM.sampling.seededRandom(1))
  const draws = []
  for (let i = 0; i < 2000; i++) draws.push(gaussian())
  return VM.distributions.histogramBins(draws, 6, {lo: -3, hi: 3})
}

See the starter’s distribution-explorer.qmd for the histogram-under-a-curve chart.

VM.distributions.sampleStats(values, opts?)

Mean, variance and standard deviation of an array of draws, in one pass (Welford’s update, which stays accurate when the mean is large compared with the spread).

Parameter Type Default Description
values number[] The draws.
opts.ddof number 1 The variance divides by n − ddof: 1 is the unbiased sample variance, 0 the population variance of the values themselves (NumPy’s np.var default).

Returns {n, mean, variance, sd}. mean is NaN for an empty array; variance and sd are NaN when n ≤ ddof.

VM.distributions.sampleStats([2, 4, 4, 4, 5, 5, 7, 9], {ddof: 0})

Discrete masses

All return 0 when k is not an integer in the support.

VM.distributions.bernoulliPmf(k, p)

P(K = 1) = p, P(K = 0) = 1 − p; 0 for any other k. p is not validated.

VM.distributions.binomialPmf(k, n, p)

Exactly k successes in n independent trials with success probability p. p ≤ 0 puts all mass on k = 0, p ≥ 1 all mass on k = n.

VM.distributions.poissonPmf(k, lambda)

λ^k e^{−λ} / k! for integer k ≥ 0. lambda ≤ 0 puts all mass on k = 0.

VM.distributions.geometricPmf(k, p)

Trials until the first success: (1 − p)^{k−1} p for k = 1, 2, 3, … – not the competing “failures before the first success” convention whose support starts at 0. p is not validated.

VM.distributions.negativeBinomialPmf(k, r, p)

Trials until the r-th success, so the support is k = r, r+1, … and r = 1 is exactly geometricPmf. 0 when p is outside (0, 1]; p = 1 puts all mass on k = r.

VM.distributions.hypergeometricPmf(k, N, K, n)

Exactly k successes when drawing n items without replacement from a population of N containing K successes: C(K, k)·C(N−K, n−k) / C(N, n). Support is max(0, n − (N − K)) ≤ k ≤ min(n, K); 0 there and for any invalid (N, K, n).

Continuous densities

VM.distributions.exponentialPdf(x, rate)

Mean 1 / rate. 0 for x < 0 or rate ≤ 0.

VM.distributions.normalPdf(x, mean, variance)

Parameterized by variance, not standard deviation: pass sd * sd. 0 for variance ≤ 0.

VM.distributions.gammaPdf(x, shape, rate)

Parameterized by rate, not scale: the mean is shape / rate. For a scale θ pass 1 / θ. Valid for any real shape > 0. 0 for x < 0 or a non-positive parameter; at x = 0 the density’s limit (rate for shape = 1, Infinity below 1, 0 above).

VM.distributions.chiSquaredPdf(x, k)

k degrees of freedom – exactly gammaPdf(x, k/2, 1/2).

VM.distributions.betaPdf(x, a, b)

On [0, 1], 0 outside it or for a non-positive shape. At an endpoint it is the density’s limit there: at x = 0, b when a = 1 (so betaPdf(0, 1, 1) is 1), Infinity when a < 1, 0 when a > 1; x = 1 likewise with a and b swapped.

VM.distributions.studentTPdf(x, k)

k degrees of freedom, any real k > 0 (not only an integer). 0 for k ≤ 0.

VM.distributions.fPdf(x, d1, d2)

d1 numerator and d2 denominator degrees of freedom. 0 for x ≤ 0 or a non-positive parameter.

VM.distributions.lognormalPdf(x, mean, variance)

The density of e^X for X ~ Normal(mean, variance). The parameters describe the underlying normal, not the log-normal’s own mean (exp(μ + σ²/2)) and variance. 0 for x ≤ 0 or variance ≤ 0.

VM.distributions.cauchyPdf(x, location, scale)

The Cauchy has no mean and no variance, so location is its median and scale its half-width at half-maximum. 0 for scale ≤ 0.

VM.distributions.weibullPdf(x, shape, scale)

Parameterized by scale, not rate, so shape = 1 is the exponential with rate 1 / scale. Shape below 1 gives a failure rate that falls with age, above 1 one that rises. 0 for x < 0 or a non-positive parameter; at x = 0 the density’s limit: 1/scale when shape = 1, Infinity below 1, 0 above.

CDFs and quantiles

For a critical value, a p-value, or the exact answer a Monte Carlo estimate is compared against.

VM.distributions.regularizedGamma(a, x)

The regularized incomplete gamma functions: lower is P(a, x), the CDF at x of a Gamma(shape a, rate 1) variable, and upper is Q(a, x) = 1 − P(a, x). So regularizedGamma(shape, rate * x).lower is the Gamma(shape, rate) CDF. Both are returned because each is computed directly where it is accurate (the series below a + 1, the continued fraction above), so a small tail probability keeps its relative precision instead of coming out as 1 − 1 = 0.

Returns {lower, upper}. {lower: 0, upper: 1} for x ≤ 0; both NaN for a ≤ 0 or a NaN input.

VM.distributions.normalCdf(x, mean?, variance?)

P(X ≤ x) for X ~ Normal(mean, variance), defaulting to the standard normal. Parameterized by variance, like normalPdf. Accurate to about 1e-15, and relatively accurate far into either tail: normalCdf(-10) is about 7.6e-24, not 0. NaN for variance ≤ 0.

VM.distributions.normalQuantile(p, mean?, variance?)

The inverse of normalCdf: normalQuantile(0.975) is the 1.96 of a 95% confidence interval. Acklam’s approximation refined by one Halley step, so it is accurate to double precision (for p below about 1e-300, where the step would overflow, the approximation alone: ~1e-9 relative). -Infinity at p = 0, Infinity at p = 1, NaN outside [0, 1] or for variance ≤ 0.

VM.distributions.chiSquaredCdf(x, k)

k degrees of freedom – exactly regularizedGamma(k / 2, x / 2).lower. 0 for x ≤ 0.

VM.distributions.chiSquaredQuantile(p, k)

The x with chiSquaredCdf(x, k) = p, i.e. the critical value of a chi-squared test at significance 1 − p. Found by bisection, so it is exact to about 1e-12 relative but costs a hundred or so CDF evaluations: compute a critical value once, not inside a loop over thousands of points. 0 at p = 0, Infinity at p = 1, NaN outside [0, 1] or for k ≤ 0.

VM.distributions.regularizedBeta(a, b, x)

The regularized incomplete beta function: lower is I_x(a, b), the CDF at x of a Beta(a, b) variable, and upper is 1 − I_x(a, b). The Student’s t and F CDFs are built on it, as the normal and chi-squared ones are on regularizedGamma, and for the same reason both halves are returned: each is computed directly on its own side of the branch point, so a tiny tail keeps its relative precision. x outside [0, 1] is clamped.

Returns {lower, upper}. {lower: 0, upper: 1} for x ≤ 0, {lower: 1, upper: 0} for x ≥ 1; both NaN for a ≤ 0, b ≤ 0 or a NaN input.

VM.distributions.studentTCdf(t, k)

P(T ≤ t) for Student’s t with k degrees of freedom (k need not be an integer, as Welch’s test needs). Relatively accurate far into either tail, so take an upper tail as studentTCdf(-t, k), which is the same number by symmetry, rather than 1 − studentTCdf(t, k). NaN for k ≤ 0.

VM.distributions.studentTQuantile(p, k)

The inverse of studentTCdf: studentTQuantile(0.975, 15) is the 2.131 of a two-sided t-test at 5%. Bisection, like chiSquaredQuantile, to about 1e-12 relative. -Infinity at p = 0, 0 at p = 0.5, Infinity at p = 1, NaN outside [0, 1] or for k ≤ 0.

VM.distributions.fCdf(x, d1, d2)

P(X ≤ x) for X ~ F(d1, d2), numerator degrees of freedom first: the null distribution of a variance ratio and of ANOVA’s F statistic. 1 − fCdf(x, d1, d2) is an upper tail to about 1e-16 absolute; for a smaller one with its relative precision, take regularizedBeta(d2 / 2, d1 / 2, d2 / (d1 * x + d2)).lower (not regularizedBeta(d1 / 2, d2 / 2, d1 * x / (d1 * x + d2)).upper, whose argument rounds so close to 1 that the tail is lost) – and pass it as hypothesisTest’s sf. 0 for x ≤ 0; NaN for d1 ≤ 0 or d2 ≤ 0.

VM.distributions.fQuantile(p, d1, d2)

The inverse of fCdf: fQuantile(0.95, 12, 15) is 2.475. Bisection, to about 1e-12 relative. A table’s lower critical value, which it gives as 1 / F(α; d2, d1), is just fQuantile(alpha, d1, d2) here. 0 at p = 0, Infinity at p = 1, NaN outside [0, 1] or for non-positive degrees of freedom.

({
  z95: VM.distributions.normalQuantile(0.975),
  chi2_95_3df: VM.distributions.chiSquaredQuantile(0.95, 3),
  t975_15df: VM.distributions.studentTQuantile(0.975, 15),
  f95_12_15: VM.distributions.fQuantile(0.95, 12, 15),
  upperTailBeyond2: 1 - VM.distributions.normalCdf(2)
})

Hypothesis tests

VM.distributions.hypothesisTest(dist, observed, opts?)

The decision of a test whose statistic has a known continuous null distribution: critical values, rejection region, p-value, and the tail intervals the p-value is the area of, which is what a chart shades. dist is {cdf, quantile}, plus optionally sf, an upper tail computed directly, which keeps a p-value below about 1e-16 from rounding to 0. Any of the CDF/quantile pairs above fits, symmetric or skewed.

Option Default
alternative "two-sided" "less" rejects small statistics, "greater" large ones
alpha 0.05 the significance level

A two-sided test puts α/2 in each tail. Its p-value is twice the smaller tail, and pValueRegion is the tail the statistic fell in plus the tail of equal area on the other side: |T| ≥ |t| for z and t; for a skewed statistic (a chi-squared variance test, an F variance ratio) the two boundaries aren’t mirror images.

Returns {pValue, reject, critical, rejectionRegion, pValueRegion}. critical holds one value (one-sided) or the lower and upper (two-sided); the two regions are arrays of [a, b] intervals with ±Infinity for an open end; reject is pValue <= alpha. A two-sided pValueRegion’s mirrored interval is empty ([Infinity, Infinity]) once the statistic’s tail is below double precision. Inputs aren’t validated: an unknown alternative is treated as two-sided, and a NaN statistic gives a NaN p-value.

{
  const df = 15
  const t = {cdf: x => VM.distributions.studentTCdf(x, df), quantile: p => VM.distributions.studentTQuantile(p, df)}
  return VM.distributions.hypothesisTest(t, -2, {alternative: "less", alpha: 0.05})
}
