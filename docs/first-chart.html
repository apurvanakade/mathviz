Building a page

The pattern every page follows, one cell at a time

This is the whole of the starter’s index.qmd, with each cell explained. Read it once and every other page will look familiar: a panel of inputs, a cell or two of computation, a chart block.

The page

VM = window.VM
viewof fText = Inputs.text({label: "f(x)", value: "sin(x) + x/3"})
viewof k = Inputs.range([1, 5], {label: "Frequency", step: 0.1, value: 1})
vmTheme = Generators.observe(notify => VM.plotting.onThemeChange(notify))
chartColors = VM.plotting.colors(vmTheme)
mainPlot = {
  const f = VM.expressions.makeFunction(math, fText)
  const xs = [], ys = []
  for (let i = 0; i <= 400; i++) {
    const x = -6 + 12 * i / 400
    xs.push(x)
    ys.push(f ? f(k * x) : NaN)
  }
  const div = document.createElement("div")
  div.className = "plotly-box-large"
  Plotly.newPlot(div, [
    {x: xs, y: ys, mode: "lines", name: fText, line: {color: chartColors.fn, width: 2.5}, showlegend: false}
  ], VM.plotting.layout({
    xaxis: {title: "x"},
    yaxis: {title: "f(kx)"},
    annotations: f ? [] : VM.plotting.emptyState("Couldn't parse that expression")
  }), VM.plotting.config())
  VM.plotting.autoResize(div)
  return div
}

Type something unparseable into the field. Toggle the theme. Press ▶ on the slider.

Cell by cell

The panel

::: {.ojs-panel .ojs-row}
```{ojs}
viewof fText = Inputs.text({label: "f(x)", value: "sin(x) + x/3"})
```
```{ojs}
viewof k = Inputs.range([1, 5], {label: "Frequency", step: 0.1, value: 1})
```
:::

A Quarto div with two classes around ordinary Observable inputs. ojs-panel is the look – border, background, consistent input styling; ojs-row is the layout – one wrapping row, the first control stretching to fill. The slider gets its play button for free. All the classes are on the Markup page.

The theme pair

vmTheme = Generators.observe(notify => VM.plotting.onThemeChange(notify))
chartColors = VM.plotting.colors(vmTheme)

Put these two lines on every chart page. chartColors is the palette – chartColors.fn, .alt, .ok, … – and it changes when the reader toggles light/dark, so every cell that reads it redraws with the right colors. Without them, the chart’s axes follow the toggle but your traces keep their old colors. (Why that is, and why colors takes an argument it ignores: onThemeChange.)

The function

const f = VM.expressions.makeFunction(math, fText)

math is the math.js global the extension loaded. makeFunction turns the typed text into a JavaScript function, or gives null if it won’t parse – it never throws, so a half-typed expression can’t break the page. Where evaluation fails (sqrt(x) at x = -1) the function gives NaN, which Plotly draws as a gap.

The sampling loop

for (let i = 0; i <= 400; i++) {
  const x = -6 + 12 * i / 400
  xs.push(x)
  ys.push(f ? f(k * x) : NaN)
}

A plain loop filling xs and ys. For a probability density, sampleCurve does this for you.

The chart

const div = document.createElement("div")
div.className = "plotly-box-large"
Plotly.newPlot(div, [...], VM.plotting.layout({...}), VM.plotting.config())
VM.plotting.autoResize(div)
return div

Make a div, draw into it, return it. Three library calls: layout() gives the themed layout with your own axis titles merged in, config() the sensible Plotly config, and autoResize() sizes the chart once it’s on the page. plotly-box-large is the one size class shipped – full width, tall; set div.style.height for anything else.

The empty state

annotations: f ? [] : VM.plotting.emptyState("Couldn't parse that expression")

When f is null the chart would be an empty grid, indistinguishable from a valid function that’s off-screen. emptyState puts a message in the middle so the reader knows it’s their input.

The wrapper around the chart cells. It’s what the fullscreen button enlarges, and where a floating legend or a slider bar attaches. Every chart wants one, even a chart with neither today, so that adding them later is just dropping in a cell.
