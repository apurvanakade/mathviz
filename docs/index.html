mathviz

Themed charts, control panels and numerical helpers for interactive math pages

mathviz is the machinery behind Visual Math Lab, packaged so any site can use it: a Quarto extension that drops into an OJS page with one line of front matter, and the same code as a plain script bundle for everything else.

Every chart, panel and slider on this site is drawn by the library itself. Toggle the theme in the navbar and watch them follow.

VM = window.VM
vmTheme = Generators.observe(notify => VM.plotting.onThemeChange(notify))
chartColors = VM.plotting.colors(vmTheme)
viewof heroF = Inputs.text({label: "f(x)", value: "sin(x) + x/3"})
viewof heroK = Inputs.range([0.5, 4], {label: "k", step: 0.05, value: 1})
{
  const f = VM.expressions.makeFunction(math, heroF)
  const df = VM.expressions.makeDerivative(math, heroF)
  const xs = [], ys = [], dys = []
  for (let i = 0; i <= 400; i++) {
    const x = -6 + 12 * i / 400
    xs.push(x)
    ys.push(f ? f(heroK * x) : NaN)
    dys.push(df ? heroK * df(heroK * x) : NaN)
  }
  const div = document.createElement("div")
  div.className = "plotly-box-large"
  div.style.height = "380px"; div.style.minHeight = "0"
  Plotly.newPlot(div, [
    {x: xs, y: ys, name: "f(kx)", line: {color: chartColors.fn, width: 2.5}},
    {x: xs, y: dys, name: "d/dx f(kx)", line: {color: chartColors.alt, width: 1.5, dash: "dot"}}
  ], {
    xaxis: {title: "x"},
    legend: {x: 0.01, y: 0.99},
    annotations: f ? [] : VM.plotting.emptyState("Couldn't parse that expression")
  })
  VM.plotting.autoResize(div)
  return div
}

Quick start

  • A new site
  • An existing Quarto site

Copy the starter – a complete Quarto website with seven working pages and the extension already installed:

git clone https://github.com/apurvanakade/mathviz
cp -r mathviz/starter my-site && cd my-site
quarto preview

Then copy any page (index.qmd is the smallest), rename it, and edit its cells. Its README lists what each page shows.

quarto add apurvanakade/mathviz
# _quarto.yml
filters:
  - mathviz

Every page now has VM, math.js, Plotly and the stylesheet. Copy a page from the starter into your site to see it work.

What you get

  • Themed charts – Plotly and Observable Plot follow your site’s light/dark toggle, with no per-page code.
  • Control panels – a few ojs-* classes lay Observable inputs out into a tidy panel; step sliders sit above the chart and get a play button.
  • A better modebar and a draggable legend – fullscreen, gentler zoom, pan by default; a floating legend that toggles traces.
  • Numerical helpers – safe expression parsing, ODE steppers, quadrature, fits, densities, seeded randomness.
